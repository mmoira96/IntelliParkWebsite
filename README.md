# IntelliPark marketing website

Responsive static website using the original Figma logo from Brand v1 (node 7:7522). Other product visuals are illustrative HTML/CSS previews, not actual screenshots. Forecasting and commercial plans are described as proposed. No fabricated customers, metrics, or testimonials.

## Preview
From this folder, run `python -m http.server 4173 --bind 127.0.0.1`, then open http://127.0.0.1:4173.

## Deploy to Vercel
Import this folder as a GitHub repository. Select Other as the framework, leave the build command empty, and use the repository root as output. No dependencies or build required.

## Demo requests
The form validates required fields and previews a submission confirmation. It does not send, store, or book anything. Connect a booking service or server endpoint before accepting real requests. Do not put email API keys in browser JavaScript.

## Design
Figma Brand v1 takes priority. Taste Skill and UI UX Pro Max guidance informed direction; their packages could not be downloaded in this environment, so bundled scripts were not run. The opening uses a CSS adaptation of the inspected Figma assembly timing, rather than an exported video.
